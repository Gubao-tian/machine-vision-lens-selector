# 工业视觉选型工具

面向工业机器视觉项目的**相机 / 镜头 / 光源**一体化选型工具。输入**最大视野**与**精度要求**，正向推导所需相机像素规格并据此匹配镜头；再按被测物类型、检测目标与反光特性推荐光源方案，输出可直接交付客户的方案摘要。

纯静态网页，零依赖，手机与电脑通用。

## 选型逻辑

### 1. 由精度反算相机分辨率

按工业视觉通行的 **3 像素准则**——最小可检特征需 3 个像素覆盖才能稳定判定其位置与尺寸：

```
像素分辨率 = 精度要求 ÷ 3
所需像素数 = FOV ÷ 像素分辨率
```

例：视野 80×60mm、精度 120µm → 像素分辨率 40µm/px → 需 2000×1500 像素（约 3MP）。

### 2. 相机推荐评分

| 维度 | 权重 | 说明 |
|---|---|---|
| 像素匹配 | 45% | 像素余量 1.15～1.8× 最优，过小无容错、过大浪费成本带宽 |
| 镜头库靶面覆盖 | 15% | 推荐靶面必须能配到镜头，否则方案不可落地 |
| 快门适配 | 15% | 运动被测物必须用全局快门，卷帘快门会拖影形变 |
| 预算档位 | 15% | 经济 / 主流 / 高端 |
| 像元灵敏度 | 10% | 像元 ≥3.4µm 灵敏度好；<2.2µm 需强化照明 |

### 3. 焦距计算（薄透镜近似）

```
放大倍率 β = 传感器尺寸 ÷ FOV      （取宽、高两方向中较严者）
焦距     f = WD × β ÷ (1 + β)
```

FA 定焦镜头焦距为离散档位（8/12/16/25/35/50mm），实际需求往往落在档位之间。工具通过**反算精确覆盖视野所需的 WD** 来补偿，并给出建议值：

```
建议 WD = f × (1 + β) ÷ β
```

若无法调整 WD，则可用接圈补偿倍率，工具会估算所需接圈长度。

### 4. 景深估算

```
DOF ≈ 2 × F × c × (1 + β) ÷ β²
```

其中 `F` 为使用光圈、`c` 为允许弥散圆（取 2 倍像素尺寸）。高度差超过景深时画面边缘会虚焦。

### 5. 远心镜头判据

远心镜头消除透视误差，但工作距离固定、价格高、视场通常较小。是否必需，用物理量判断而非经验阈值：

```
透视偏移 = 高度差 × (半像面尺寸 ÷ WD)
```

当透视偏移超过要求精度的 30% 时，普通 FA 镜头的近大远小效应不可忽略，才建议远心。

### 6. 硬性约束筛选

| 约束 | 处理方式 |
|---|---|
| 像圈覆盖 | 镜头像圈须 ≥ 相机对角线，留 3% 标称容差 |
| 接口匹配 | C / CS / M12 / M42 / F 口须一致 |
| 最近物距 MOD | WD 不得小于镜头最近合焦距离 |
| 解析力 | 镜头标称像素 < 相机 0.4× 时淘汰，其余按差距分级降权并警示 |

无匹配结果时，按各镜头被淘汰的原因占比输出针对性诊断建议。

### 7. 光源选型

光源选型按「场景规则矩阵 + 加权评分」实现，覆盖四类典型被测物：

| 场景 | 推荐打光方式 | 首选光源类型 |
|---|---|---|
| 金属件划痕/压伤 | 暗场 · 低角度斜射 | 低角度环形光 / 条形光 |
| 曲面反光件 | 漫射 · 穹顶均匀照明 | 穹顶漫射光 / 同轴光 |
| 印刷标签 | 明场 · 高角度均匀照明 | 高角度环形光 / 条形光 |
| 透明玻璃 | 背光透射 + 低角度暗场 | 背光源 / 低角度环形光 |

评分维度与权重：

| 维度 | 权重 | 说明 |
|---|---|---|
| 打光方式 | 32% | 明场/暗场/背光/漫射与场景的匹配度 |
| 光源类型 | 32% | 环形/条形/同轴/穹顶/背光等与检测目标的适配 |
| 反光适配 | 14% | 镜面件优先漫射/同轴，哑光件可用低角度直射 |
| 颜色还原 | 12% | 需真实颜色时按显色指数 CRI 评分 |
| 频闪适配 | 10% | 运动检测优先支持频闪的型号 |
| 预算 | 8% | 经济 / 主流 / 高端 |

光源**发光面尺寸下限**由视野反推（按光源形态取 1.0～1.3 倍视野对角线/长边，向上取整到 10mm）；背光可行性、WD 与安装空间冲突、颜色需求冲突均纳入降权与风险提示。按光源类型去重，每类最多保留 2 款。

## 项目结构

```
index.template.html         HTML 骨架源码（含外链引用）
index.html                  构建产物：自包含单文件（发布用）
css/style.css               样式源码
js/lens-data.js             相机库 + 镜头库 + 光源库 + 计算引擎
js/app.js                   渲染、交互、方案摘要导出
build/build-standalone.js   从模板将 CSS/JS 内联为单文件
build/extract-template.js   一次性工具：从旧单文件反向提取模板与源码
test/engine.test.js         引擎测试（相机/镜头 5 工况 + 光源 4 场景 + 6 项约束）
```

### 修改流程

```bash
# 1. 修改源码（index.template.html / css/ / js/）
# 2. 重新生成单文件
node build/build-standalone.js
# 3. 运行测试（须全部通过）
node test/engine.test.js
```

`index.html` 是构建产物，**不要直接编辑**，改动会在下次构建时被覆盖。

## 型号库

全部为**市面在售的真实品牌型号**，以 CST 康视达为主、海康威视 / 奥普特 / 长步道等国内主流为辅。参数依厂商公开规格书录入，定型前仍须复核。

- **相机**（11 款，带 `brand` + `model`，推荐卡直接显示可采购型号）
  - CST 康视达 `CST-CG` / `CST-CR` 系列（CG050-75UM、CG030-36GM、CR200-6GM 等）
  - 海康威视 HIKROBOT `MV-CS` 系列（MV-CS050-10GM / 10UM、MV-CS023-10GM）
- **镜头**（40 款）
  - CST 康视达 `CST-B` 系列 FA 定焦（B-5M / B-10M）、`CST-MF` 物方远心
  - 海康威视 `MVL-HF` 系列、长步道 `LS-8M`、奥普特 `OPT-FA`
- **光源**（28 款）
  - CST 康视达 `RS` 环形 / `2BS` 条形 / `COS`·`HCOS` 同轴 / `DS` 圆顶 / `HFS` 面光 / `SPL` 点光 / `HRS` 环形无影
  - 奥普特 `OPT-LI` / `RI` / `LB` / `CO` / `DM` / `BL` / `SP`

### 接入自有型号库

替换 `js/lens-data.js` 中的 `LENSES`、`CAMERAS`、`LIGHTS` 数组即可，计算引擎无需改动。字段含义见文件内注释。光源场景规则在 `LIGHT_SCENES` 中按场景键配置。

## 方案摘要导出

- 保存为 PNG 图片
- 打印 / 存为 PDF

## 免责说明

所列型号为市面在售真实产品，参数依厂商公开规格书录入，仅供方案评估。定型前须：

1. 以厂商最新规格书核实像圈、MOD、畸变、MTF 与光源显色指数
2. 通过样机实测确认景深、解析力与打光效果
3. 注意实际系统精度与成像质量还受标定误差、环境光、安装空间与算法影响

计算采用薄透镜近似，非远心镜头大倍率或近距离工况下存在偏差；光源推荐为启发式规则评估，须以打光实验最终确定。

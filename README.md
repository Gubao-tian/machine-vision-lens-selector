# 工业镜头选型工具

面向工业机器视觉项目的相机与镜头选型工具。输入**最大视野**与**精度要求**，正向推导所需相机像素规格，并据此匹配可用镜头，输出可直接交付客户的方案摘要。

纯静态网页，零依赖、零构建步骤，手机与电脑通用。

## 使用方式

直接打开 `index.html` 即可，无需服务器、无需安装。

- **在线版**：通过分享链接访问
- **离线版**：`index.html` 是自包含单文件（样式与脚本全部内联），可直接发给他人双击打开

## 选型逻辑

### 1. 由精度反算相机分辨率

按工业视觉通行的 **3 像素准则**——最小可检特征需 3 个像素覆盖才能稳定判定其位置与尺寸：

```
像素分辨率 = 精度要求 ÷ 3
所需像素数 = FOV ÷ 像素分辨率
```

例：视野 80×60mm、精度 120µm → 像素分辨率 40µm/px → 需 2000×1500 像素（约 3MP）。

### 2. 相机推荐评分

| 维度 | 权重 | 说明 |
|---|---|---|
| 像素匹配 | 45% | 像素余量 1.15～1.8× 最优，过小无容错、过大浪费成本带宽 |
| 镜头库靶面覆盖 | 15% | 推荐靶面必须能配到镜头，否则方案不可落地 |
| 快门适配 | 15% | 运动被测物必须用全局快门，卷帘快门会拖影形变 |
| 预算档位 | 15% | 经济 / 主流 / 高端 |
| 像元灵敏度 | 10% | 像元 ≥3.4µm 灵敏度好；<2.2µm 需强化照明 |

### 3. 焦距计算（薄透镜近似）

```
放大倍率 β = 传感器尺寸 ÷ FOV      （取宽、高两方向中较严者）
焦距     f = WD × β ÷ (1 + β)
```

FA 定焦镜头焦距为离散档位（8/12/16/25/35/50mm），实际需求往往落在档位之间。工具通过**反算精确覆盖视野所需的 WD** 来补偿，并给出建议值：

```
建议 WD = f × (1 + β) ÷ β
```

若无法调整 WD，则可用接圈补偿倍率，工具会估算所需接圈长度。

### 4. 景深估算

```
DOF ≈ 2 × F × c × (1 + β) ÷ β²
```

其中 `F` 为使用光圈、`c` 为允许弥散圆（取 2 倍像素尺寸）。高度差超过景深时画面边缘会虚焦。

### 5. 远心镜头判据

远心镜头消除透视误差，但工作距离固定、价格高、视场通常较小。是否必需，用物理量判断而非经验阈值：

```
透视偏移 = 高度差 × (半像面尺寸 ÷ WD)
```

当透视偏移超过要求精度的 30% 时，普通 FA 镜头的近大远小效应不可忽略，才建议远心。

### 6. 硬性约束筛选

| 约束 | 处理方式 |
|---|---|
| 像圈覆盖 | 镜头像圈须 ≥ 相机对角线，留 3% 标称容差 |
| 接口匹配 | C / CS / M12 / M42 / F 口须一致 |
| 最近物距 MOD | WD 不得小于镜头最近合焦距离 |
| 解析力 | 镜头标称像素 < 相机 0.4× 时淘汰，其余按差距分级降权并警示 |

无匹配结果时，按各镜头被淘汰的原因占比输出针对性诊断建议。

## 项目结构

```
index.html               构建产物：自包含单文件（发布用）
css/style.css            样式源码
js/lens-data.js          相机库 + 镜头库 + 计算引擎
js/app.js                渲染、交互、方案摘要导出
build/build-standalone.js  将 CSS/JS 内联为单文件
test/engine.test.js      计算引擎测试（5 个典型工况）
```

### 修改流程

```bash
# 1. 修改源码（css/ js/）
# 2. 重新生成单文件
node build/build-standalone.js
# 3. 运行测试
node test/engine.test.js
```

`index.html` 是构建产物，**不要直接编辑**，改动会在下次构建时被覆盖。

## 型号库

内置 44 款示例型号：

- **Computar** MP2 / MPW2 系列
- **Kowa** LM-HC / LM-JC 系列
- **VST** VS-H1 系列
- **长步道** LS-8M 系列
- **Moritex** ML-MC 系列、MML-HR 物方远心系列

相机侧覆盖 9 档真实传感器规格（Sony IMX264 / IMX178 / IMX304 / IMX183 等）。

### 接入自有型号库

替换 `js/lens-data.js` 中的 `LENSES` 与 `CAMERAS` 数组即可，计算引擎无需改动。字段含义见文件内注释。

## 方案摘要导出

点「生成方案摘要」输出一页方案卡，含相机规格、推荐镜头、备选与风险要点，可：

- 保存为 PNG 图片
- 打印 / 存为 PDF

## 免责说明

型号参数为**示例近似值**，用于方案评估与方法演示。定型前须：

1. 以厂商最新规格书核实像圈、MOD、畸变与 MTF
2. 通过样机实测确认景深与边缘解析力
3. 注意实际系统精度还受镜头畸变、标定误差、照明条件与算法影响

计算采用薄透镜近似，非远心镜头大倍率或近距离工况下存在偏差。
